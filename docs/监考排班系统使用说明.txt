========================================================
  监考排班系统 · 使用说明
========================================================

【一、怎么打开】
  双击文件夹里的「监考排班系统.exe」即可。
  首次打开若出现蓝色「Windows 已保护你的电脑」提示：
    点「更多信息」→「仍要运行」。

  如果双击 exe 没反应，请改双击「启动（调试模式）.bat」，
  它会把错误信息显示出来（截图发回即可定位）。

【二、不用装任何东西】
  本文件夹已自带 Python 运行环境（python 子文件夹），
  支持 Windows 7 SP1 / 8 / 10 / 11（64 位），
  无需安装 Python、也不需要联网。

  注意：请把【整个文件夹】一起复制/解压，
  不要只把 exe 单独拿出来——它需要旁边的 python 和 app 文件夹。

【三、操作顺序】
  ① 生成模板    → 生成 3 个 CSV 模板（考试 / 考场 / 老师）
  ② 导入数据    → 依次选择填好的 3 个 CSV
  ③ 一键排班    → 等待进度条到 100%（界面会显示结果）
  ④ 导出结果    → 选择保存位置，生成：
                    · 排班表.csv
                    · 老师时长统计.csv（含监考/巡场/自习/总时长）
                    · 监考安排表.xlsx（与原表格样式一致）
  ⑤ 打开结果    → 用 Excel/WPS 打开导出的文件

  ★ 重要：「③ 一键排班」只是算出结果，不会生成文件；
     必须再点「④ 导出结果」才会写文件。

【四、模板怎么填】
  · 模板_考试.csv   ：科目、日期、开始/结束时间、巡场人员
                      （巡场人员多个用空格分隔，留空=本场无巡场）
  · 模板_考场.csv   ：科目、考场、监考人数、班级名称、容量人数、标题
                      （班级名称/容量人数/标题用于导出 Excel 时
                        还原表头「第一考场(高三1班)」和第 2 行人数；
                        标题只需在第一行填一次）
  · 模板_老师.csv   ：姓名、是否参与（填 是/否）、不可用时段、必用时段
                      · 不可用时段格式：2026-10-08 08:00~2026-10-08 12:30
                        （多段用「|」分隔）
                      · 也支持：08:00~12:30（省日期）、2026-10-08（整天）
                      · 必用时段同理；没有就留空

  ★ 巡场与监考的关系：
     · 巡场人如果也在「老师模板」里，那么他巡场的那场考试期间
       **不会再给他排监考**（程序自动处理）；
     · 巡场时长会计入《老师时长统计.csv》的「巡场时长」，
       总时长 = 监考时长 + 巡场时长；
     · 校领导等不参与监考的人，直接写在巡场列即可，一样计入时长统计。

  时间也可写成 2026/10/8 8:00 这种格式。

【五、人员不足时】
  程序排班前会先检测每场「需要人数 vs 可用人数」。
  若缺人，会弹出报告并给出解决方案建议（减少监考/放宽时段/增加老师），
  此时不会生成排班结果，也不会改动你的任何文件。
  请按建议调整 CSV 后重新导入。

【五之二、排班公平性怎么算】
  · 每位老师的「总时长」= 监考时长 + 巡场时长，两者同权，尽量拉齐；
  · 每天的休息也尽量平均：工具栏有「每天休息均衡」下拉，
      - 适中（推荐）：谁都不会在某一天被排满（例如第二天 5 场全监考），
        同时总时长仍然接近；
      - 严格：每天连场次都一样多，代价是总时长允许差得稍多一点；
      - 关闭：回到旧行为，只保证总时长接近。
  · 「自习岗」（单人看考场的考场）在老师之间尽量平均分配；
  · 《老师时长统计.csv》新增「每天场次」「每天时长」两列
    （如 3/4 表示第一天 3 场、第二天 4 场），可直接核对每天是否平均。

【六、常见问题】
  · 提示缺少 xxx.dll / 无法启动程序
      → 请用「启动（调试模式）.bat」，把报错截图发回。
  · 导出后找不到文件
      → 文件在「④ 导出结果」时你选择的文件夹里。
  · Excel 打开 xlsx 提示格式错误
      → 请确认用的是 Excel 2007 以上或 WPS。
  · 导入时报 'utf-8' codec can't decode byte 0xd0...
      → 模板被 Excel/WPS 另存过，变成了 GBK 编码（中文 Windows 默认）。
        本版程序已能自动识别（会提示「已按 GB18030 自动识别」），直接导入即可。
  · 老师填了不可用时间却仍被排监考
      → 导入后请看日志里的提示（例：老师表：共 40 人；其中 6 人填了不可用时段）。
        若显示 0 人，说明这一列没被读到：确认列名是「不可用时段」
        （「不可用时间」「请假时间」等也能识别），且填在「老师」表里。
        时段写法不对时程序会直接报错并指出是第几行哪位老师，不会默默忽略。
